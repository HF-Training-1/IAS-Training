# IAS Training — Training and Development

Professional training & development platform for assessors and learners.

## 🚀 Live Site
👉 **[Go to IAS Training](https://h-training-1.github.io/IAS-Training/)**

## 📁 File Structure
- `index.html` — Login page
- `register.html` — Step 1: Account details
- `set-password.html` — Step 2: Create password
- `dashboard.html` — User dashboard & files
- `style.css` — Shared design
- `script.js` — Login logic & master admin settings

## 🔑 Master Admin
Edit `script.js` to set your master email & password — change only the top section.

## ✏️ Adding Content
Edit `dashboard.html` → add file links in the **Your Training Files** section.
